The Archway

An arched opening seen straight on: cyan outline, warm light in the passage, the wall's thickness thrown as shadow across the right, and one figure at the threshold for scale. The mark is about a person walking into somewhere — everything below exists to protect that.

Construction

grid unit u = 1/8 of width

Width 8u, height 10u. The arch radius is exactly 4u, so the head is a true semicircle and never a squashed oval. The shadow arch is the same shape offset 2.6u right and 1.1u down.

Knockouts

four permitted grounds

On paper the light darkens to #E2A100 so it holds against white. On either accent the light becomes navy and the outline disappears — the arch is then defined by the shadow alone, which still works because the shadow is the shape.

Size ladder

what drops, when

The figure is the first thing to go, below 48px tall. Everything below that is the arch, the light and the shadow — three shapes, which is why it survives to 16px.

four ways it breaks · arch only, so each fault reads clean

Production note

These are drawn in HTML at the sizes shown, which is fine for review but not for handoff. The production mark needs redrawing as SVG on the 8×10u grid above, with the figure as a single compound path so it can be removed for the small variants without editing geometry.

Where it's applied

The channel assets file already uses the Archway throughout — cover, profile, watermark, thumbnail, Short and all three ad sizes. The Cyanotype kit is swapped too — identity lockups, knockouts, watermark and the end-plate build all use the Archway. Nothing outstanding.

02 Overlays, cards, transitions, outro

Eight overlays, four cards, four cuts

Everything that appears over footage, plus the engagement cards, the four transitions and the three-beat outro. The rule that governs all of it is no filled plates — type sits on footage with outlines, hairlines and brackets doing the work a box would normally do.

Transitions

Four cuts, made of the same parts

A rule, a crop mark, a grid and a dimension bracket — the same four shapes the overlays are built from, which is why a cut never reads as a plugin. Demos loop; the real ones fire once.

Dimension push · 420ms
A measuring bracket extends and the shots slide with it, as if the cut were being dimensioned. Fastest of the four; good for a rapid run of objects.
Outro

Three beats, then the arch lights

Takeaway, next-video card, end plate. The end plate is the payoff for the whole identity: the arch draws, the light rises and the figure arrives at the threshold, which is the last thing on screen.

The one rule that keeps it coherent

No filled plates, and one yellow moment per frame. If two things are yellow, neither is the thing to look at. When bright footage threatens legibility the answer is always a gradient scrim, never a box — the box is what makes a kit look like a template.

What this replaces

Midnight, and the earlier chip-and-outline kit built on it. Both are still in the project for reference but nothing new should be drawn in them. Say the word and I'll rewrite the Claude Code handoff package around this file.
